# cauce-server/web

The Svelte 5 SPA is the only UI layer (FX-06 removed the framework-free
`src/` bundle, the htmx deps and the rolldown `build.mjs`). The
repository-root AGENTS.md still applies.

## The SPA (`src/spa/`)

Svelte 5 + Vite (`pnpm run build:spa` → committed `assets/spa/`, embedded by
rust-embed, served at `GET /app`; the legacy `/`, `/search`, `/answer`
paths redirect onto it). Layout (`src/spa/`): `app/` entry + shell +
`app.css`; `ui/` vendored primitives; `lib/` api/sse/i18n; `features/`;
`routes/` thin shells. Rules: `svelte-check` (`pnpm run check:spa`) is the
typecheck — plain tsc excludes this tree; Tailwind v4 is the only styling
system (tokens in `app.css` `@theme inline`; the small inline stylesheet
that styles the residual `/trace/{id}` and `/answer/{id}` pages mirrors
them in `src/pages/mod.rs`); features import `ui/` + `lib/` only, no
cross-feature imports.

Two typescripts coexist deliberately: `typescript ~6` is the classic API
svelte-check drives internally, and `@typescript/native` (an npm alias of
typescript@7) provides the native `tsc` binary and the `--tsgo` diagnostics
pass — do not rename or merge them, svelte-check refuses `typescript >= 7`.

## TypeScript conventions

- Strict `tsc --noEmit` (`pnpm run typecheck`) covers `src/` (the non-SPA
  trees) and `tests/`.
- Named `interface`s for object types — never inline object-literal types in
  signatures, parameters, or returns. Instead of
  `{ fetchImpl?: typeof fetch; assist?: AssistHandle | null }`, declare
  `interface StreamDeps { fetchImpl?: ...; assist?: AssistHandle | null }`.
  `type` only when an interface cannot express it (unions, `Pick`/`typeof`
  mapped types); callable slices may be interfaces with a call signature
  (`interface SseFetch { (input: string, init: RequestInit): Promise<SseResponse> }`).
- Wire types come from ts-rs (`src/types/`, generated — do not hand-edit);
  i18n string bundles from `src/i18n/*.json` (generated by `gen_i18n`).
