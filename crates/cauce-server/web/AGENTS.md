# cauce-server/web

The frontend bundle: framework-free TypeScript (`src/`) compiled by rolldown
(`build.mjs` → committed `assets/app.js`), unit-tested by vitest + happy-dom
(`tests/`). The repository-root AGENTS.md still applies.

## TypeScript conventions

- Strict `tsc --noEmit` (`pnpm run typecheck`) covers `src/` and `tests/`.
- Named `interface`s for object types — never inline object-literal types in
  signatures, parameters, or returns. Instead of
  `{ fetchImpl?: typeof fetch; assist?: AssistHandle | null }`, declare
  `interface StreamDeps { fetchImpl?: ...; assist?: AssistHandle | null }`.
  `type` only when an interface cannot express it (unions, `Pick`/`typeof`
  mapped types); callable slices may be interfaces with a call signature
  (`interface SseFetch { (input: string, init: RequestInit): Promise<SseResponse> }`).
- Wire types come from ts-rs (`src/types/`, generated — do not hand-edit);
  i18n string bundles from `src/i18n/*.json` (generated by `gen_i18n`);
  page globals (`window.S`/`SA`/`AS`, `Q`, `assistContext`) are declared in
  `src/globals.d.ts`.
