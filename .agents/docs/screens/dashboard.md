# Screen: Dashboard (`dist/dashboard/index.html`, built by `oxe stats build`)

A single self-contained static page generated by the `oxe stats build`
CLI from the `search_log` table. No JavaScript: all charts are inline
SVG, all data is baked in at build time. Open the file directly or serve
it from any static host.

## Behavior

- Fully static: no interactive elements, no JS, no external requests
  (Geist font is inlined; SVG charts inline). Works from `file://`.
- Header shows the tool name, the generation timestamp, and the stats
  window as a build-time constant (e.g. `last 30 days`). Changing the
  window means re-running the build, not clicking anything.
- Panels:
  - searches/day: 30-day bar/area chart, cache vs network stacked, so
    cache savings are visible at a glance.
  - cache hit rate: big number plus a 30d trend sparkline; sourced from
    `search_log.source` split.
  - top queries: 20 rows, query text + count, most frequent first.
  - zero-result queries: list of queries that returned no hits; useful
    for spotting backend gaps or junk traffic. Most recent first.
  - network latency: p50/p95 of `duration_ms` where `source = network`,
    drawn per day.
  - client split: one horizontal bar per client value
    (`mcp` | `http` | `web-ui`) with percentage labels.
- Empty-database state: each panel renders a flat "no data yet" line
  instead of an empty chart; the page is still generated.

## Responsive

- 2x2 bento grid for the four chart panels above ~700px, single column
  stacked below. Table and list panels are always full width.
- Pure CSS: `grid-template-columns: repeat(auto-fit, minmax(20rem, 1fr))`.
- SVG charts use `viewBox` + `width: 100%` so they scale with panels;
  text in charts stays legible down to ~20rem panel width.

## Notes

- Build command: `oxe stats build` writes `dist/dashboard/index.html`.
  DB access is read-only and WAL-safe (opens the sqlite file in RO mode
  so it never contends with the running proxy).
- stdlib only: no chart library, no template engine beyond
  `string.Template`, no JS emitted at all.
- Regenerate on demand or from a cron; the page always reflects the
  state of `search_log` at build time.
- Visual polish note: match the screens' favicon-adjacent look where
  cheap (inline SVG panels already carry the accent color), but the
  dashboard stays fully static and no-JS, 100% baked at build time.
