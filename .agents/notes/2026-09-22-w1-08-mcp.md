# 2026-09-22 — W1-08 MCP server notes

Findings from landing `oxe-server::mcp` (PR #98, issue #28):

- rmcp 3.4: `RunningService` lives at `rmcp::service::RunningService`, not the crate root.
  Client side needs features `client` + `transport-streamable-http-client` +
  `transport-streamable-http-client-reqwest`; server side `transport-streamable-http-server`
  + `transport-io`.
- `jsonschema` default features pull reqwest + rustls `rustls-no-provider`, which panics at
  runtime (`No rustls crypto provider is configured`) in tests that also use reqwest. Fix:
  `jsonschema = { default-features = false }` and `reqwest = { default-features = false }`.
- The frozen v2 Exa wire shape mixes cases: `requestId`, `searchType`, `costDollars` are
  camelCase but `tool_source` is snake_case. Field-level serde attrs per struct, not a global
  rename rule.
- `gh pr create` (GraphQL) can hit a secondary rate limit while REST still works; `gh api
  repos/<owner>/<repo>/pulls -f ... -F body=@file` is a working fallback for opening PRs.
- `oxe mcp` stdio: keep stdout protocol-only; the observability init already writes stderr +
  JSONL, so no extra plumbing was needed. The e2e test asserts clean exit on transport close.
- `/mcp` mounts through the declared `ROUTES` row via `axum::routing::any_service`;
  `CURRENT_WAVE` stays 0 — the row is a declaration, mounting is gated on the handler
  existing.
